# Code Structure

`app/`
- Gradle project root.
- Contains wrapper, version catalog, top-level build files, and the Android module.

`app/app/`
- Android application module.

`app/app/src/main/java/com/example/sourceslist/`
- `MainActivity.kt`: app entry point.
- `data/`: Room database, DAO, entity, converters, repository.
- `ui/sources/`: main Compose screen and view model.
- `ui/common/`: external actions like open/copy link.
- `ui/theme/`: Compose theme colors.

`app/app/src/main/res/`
- Android resources: strings, theme, launcher icon, backup/data-extraction XML.

`app/app/src/test/`
- Local unit tests.

`app/app/src/androidTest/`
- Instrumentation test placeholder.

`app/app/schemas/`
- Room schema export generated by KSP.

## Notes

- The intended V1 UI structure is:
  - a home screen with the existing app header and a visible `+` add action
  - three selector entries on the home screen: `Unclassified`, `Casual`, `Serious`
  - dedicated destination pages for each bracket instead of inline URL lists on the home screen
  - bracket pages for `Casual` and `Serious` that can switch to an only-read/completed view
- The app is local-first. Data is stored only in Room; there is no sync or account layer.
- `app/app/build/` contains generated build output and is not part of the source structure.
