# Sources List Intent

Simple local Android app for saving content URLs and sorting them into three brackets:
- `Unclassified`
- `Casual`
- `Serious`

UI direction:
- keep the existing `Sources List` header style
- show a visible `+` action on home for adding a URL
- use home as a selector-only screen
- open a dedicated bracket page when a selector is tapped

V1 focus:
- add, open, copy, move, delete
- mark `Casual` and `Serious` items done
- view completed items separately for `Casual` and `Serious`
